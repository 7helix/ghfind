📥 install

curl -O https://raw.githubusercontent.com/USERNAME/ghfind/main/ghfind.lua
chmod +x ghfind.lua
# ubuntu/debian
sudo apt install lua5.4 curl

# macos
brew install lua curl

🚀 usage

lua ghfind.lua "words" [opts]

  -l/--lang X      language
  -s/--sort X      stars|forks|updated
  -n/--limit N     how many
  -t/--check-token
  -r/--recommend
  -h/--help

🔐 token

Optional. Raises rate limit. No scopes needed.

export GITHUB_TOKEN=ghp_xxx
# or
echo ghp_xxx > ~/.config/ghfind/token
chmod 600 ~/.config/ghfind/token
lua ghfind.lua --check-token
lua ghfind.lua --recommend

💖 why

  • single file, zero deps
  • cute emoji output
  • built-in token scope audit
  • ships its own json parser
