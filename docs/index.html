🐣 ghfind

a tiny cute github repo searcher — pure lua

pure lua no deps single file MIT

⭐ GitHub 📥 Install

advanced (optional token)

Paste a GitHub token to raise the rate limit. Stored only in this tab, never sent anywhere but GitHub. Leave blank — no scopes needed.

📥 install the CLI

curl -O https://raw.githubusercontent.com/7helix/7helix.github.io-ghfind-/main/ghfind.lua
chmod +x ghfind.lua
lua ghfind.lua "neovim colorscheme" --sort stars

🚀 usage

lua ghfind.lua "words" [opts]

  -l/--lang X      language
  -s/--sort X      stars|forks|updated
  -n/--limit N     how many
  -t/--check-token
  -r/--recommend
  -h/--help

🔐 token

Optional. Raises rate limit. No scopes needed.

export GITHUB_TOKEN=ghp_xxx
# or
echo ghp_xxx > ~/.config/ghfind/token
chmod 600 ~/.config/ghfind/token
lua ghfind.lua --check-token
lua ghfind.lua --recommend
